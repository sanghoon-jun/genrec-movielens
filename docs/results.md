# Results

MovieLens-1M · leave-one-out · test split · full catalog (3,706 items, seen items masked)

All GenRec numbers use the **full faithful recipe**: LM loss β=0.1, 3 epochs, per-size LR (see Settings). Rows/columns vary only the model size and the prompt version (context engineering).

Baselines: **SASRec (tuned) 0.1820**, Popularity 0.0180. SASRec (chunked, ctx 20) 0.1905 trains on every position; it is the bar for GenRec-AP, not for the faithful GenRec.

**GenRec-AP** (`--all_positions`, not in the paper: the next movie is ranked after every movie in the prompt) 0.5B profile: **0.1926**, above SASRec (tuned) by 6% and level with SASRec (chunked) (+1%, within noise). Ratings in its prompts are correct (see the bug note below).

## Settings
| Item | Config |
|---|---|
| Prompts | genres: last 20 movies as `title [genres] rating`; profile: genres + `User: gender, age, occupation`; synopsis: genres + first synopsis sentence for the last 5 movies |
| GenRec | Qwen2.5 + LoRA r=16 (q,k,v,o); last-token h → LayerNorm → h·E (random-init E); L = 0.9·CE over full catalog + 0.1·LM(target title); 16 samples/user/epoch; batch 8; 3 epochs; LoRA lr 2e-4 (0.5B) / 1e-4 (1.5B, 3B) / 5e-5 (7B), head lr 1e-3; 5% (0.5B) / 10% warmup → linear decay; grad clip 1.0; bf16 |
| SASRec | d=128, 2 layers, 2 heads, max_len=200, dropout=0.2, lr=1e-3, batch=128, 200 epochs; chosen from a d × dropout × heads grid by valid NDCG@10 |
| GenRec-AP | 0.5B recipe (LoRA lr 2e-4, 5% warmup, β=0.1, 3 epochs, batch 8) with `--all_positions`: 20-movie chunks at a random offset per epoch cover every train target once (~55K prompts/epoch); h after each movie's `;` (last movie: at `Next:`, as in eval) ranks the next movie; LM loss on the target title only |
| SASRec (chunked, ctx 20) | same model with max_len=20, `--chunk`: 21-item windows at a random offset per epoch, so every train target is used once per epoch (the tuned run trains only on each user's last 201 items); batch 256, 150 epochs |
| Selection | valid NDCG@10 only; test reported once |

## Notes
- Grid: size +2–4% from 0.5B to 3B, flat at 7B (0.1610 vs 0.1615); prompts within ~3% (profile ≥ genres > synopsis); every cell 11–16% below SASRec
- 7B LoRA LR: 5e-5 kept by validation (valid 0.1733 vs 0.1726 at 1e-4; test 0.1610 vs 0.1626); the two runs match within noise at every epoch
- Backbone choice is ours: the paper uses an internal ~1B–10B LLM with Netflix-specific pretraining (Phase 1); no equivalent here
- Run-to-run noise is about ±2% (two seeds, ranking-only 0.5B); differences under ~4% are not significant
- Train time includes periodic valid eval, excludes final test eval
- Bug (fixed 2026-10-15): every GenRec run above showed the wrong ratings in the prompt. Movies were shown with the ratings of the user's last 20 movies overall, not the ratings at the prompt's cut point; at test the last movie carried the target's rating. Rerun with fixed ratings (0.5B profile): test 0.1562 vs 0.1575 with the bug (valid 0.1683 vs 0.1665), within noise, so the numbers above stand
- Timestamps are noisy: 52.9% of consecutive ratings share a timestamp → low ceiling for next-item metrics
