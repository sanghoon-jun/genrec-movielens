## Notes
- SASRec tuning (test NDCG@10): untuned d=64, 100 ep: 0.1681 → tuned 0.1820 (+8%). Same selection rule as GenRec (best valid), so both baselines got comparable tuning effort
- Backbone choice is ours: the paper uses an internal ~1B–10B LLM with Netflix-specific pretraining (Phase 1); no equivalent here
- Train time includes periodic valid eval, excludes final test eval
- Cost = pod time (training + eval) at $0.74/h (Cloud RTX 4090)
- SASRec (untuned) run-to-run variation on MPS (same seed): NDCG@10 0.1681 / 0.1701
- Same-settings comparisons (test NDCG@10): 0.5B v2 → v3: 0.1441 → 0.1500 (+4%); 0.5B → 1.5B (v2, lr 1e-4): 0.1386 → 0.1486 (+7%); 1.5B v2 → v3: 0.1486 → 0.1546 (+4%)
- Seed variance: 0.5B v3 seed 42 / 43 → 0.1500 / 0.1558 (±2% around 0.153). Gains under ~4% are within noise; the +4% prompt gain is not yet significant
- Rating-weighted loss (paper's "reward" weighting), 0.5B v3: 0.1473 — no gain (−4% vs seed mean 0.153); metric counts the next rating regardless of its value
- Prompts (3 ep): 0.5B v3 / v4 / v5 → 0.1500 / 0.1530 / 0.1520 (all within seed noise); 1.5B v3 / v4 / v5 → 0.1546 / 0.1581 / 0.1552 (v4 +2%, borderline; v5 no gain)
- Epochs: 1.5B v3 3 → 5 ep: 0.1546 → 0.1627 (+5%)
- 7B: 2 epochs (cost), lr 5e-5, 10% warmup, `--grad_ckpt`. Valid NDCG@10 vs 1.5B v3 at the same epoch: +7% (ep1), +8% (ep2); test vs 1.5B v3 at 3 epochs: +1.5%
- Warmup + grad clip are required: without them training can collapse to popularity-level
- Timestamps are noisy: 52.9% of consecutive ratings share a timestamp → low ceiling for next-item metrics
